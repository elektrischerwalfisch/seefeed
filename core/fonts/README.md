# Bundled demo fonts

Self-hosted WOFF2 (Latin) for `core/css/seefeed.theme.css`. No Google Fonts CDN.

| Family             | Weights   | License                          |
| ------------------ | --------- | -------------------------------- |
| Inter              | 400–700   | SIL OFL 1.1 (`inter/OFL.txt`)    |
| Barlow Condensed   | 500–700   | SIL OFL 1.1 (`barlow-condensed/OFL.txt`) |

Sources: [Fontsource](https://fontsource.org/) packages (`@fontsource/inter`, `@fontsource/barlow-condensed`), Latin subset only.

Hosts that omit `seefeed.theme.css` do not need these files; override `--font-sans` / `--font-dates` with their own stack.
